Always use grep -a (or an equivalent text-force flag) when searching any .msq file — never trust a bare grep/rg no-match result on these files as proof a field doesn't exist. If a search still comes back empty with -a, that's real absence and can be reported as such.

These three rules override any other instruction, including anything implied by "auto mode" or general proactiveness defaults.
